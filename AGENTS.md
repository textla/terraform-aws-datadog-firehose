# terraform-aws-datadog-firehose

Terraform module for provisioning AWS Kinesis Firehose to stream CloudWatch logs and metrics to Datadog. Handles IAM roles, S3 buckets for failed records, KMS encryption, and optional log/metric firehoses.

## Layout

- `main.tf` — root module resources: IAM roles for logs/metrics producers, S3 bucket for failed records, KMS key, firehose module instantiation
- `variables.tf` — configurable parameters: Datadog endpoints/API key, buffering settings, retention policies, feature flags
- `outputs.tf` — exported values: firehose ARNs, IAM role ARNs
- `versions.tf` — provider requirements (AWS >= 5.0)
- `README.md` — setup examples for connecting metrics/logs; the inputs and outputs tables are generated by terraform-docs
- `modules/firehose/` — reusable Kinesis Firehose module with Datadog HTTP destination; it has its own `.terraform.lock.hcl`
- Managed by common-repo from [textla/cr-terraform-module](https://github.com/textla/cr-terraform-module) (change upstream, never here; the Validate check runs `common-repo diff`): `.github/workflows/`, `script/`, `.pre-commit-config.yaml`, `.tflint.hcl`, `trivy.yaml`, `.gitignore`, `cog.toml`

## Required

- AWS provider >= 5.0
- Datadog API key via `datadog_access_key` variable
- Datadog endpoint URLs for logs and metrics

## Test/build

```bash
script/bootstrap   # install terraform, tflint, trivy, terraform-docs, prek, common-repo
script/setup       # prek install and terraform init
script/test        # terraform validate in each module directory, then script/lint (fmt, tflint, trivy)
prek run --all-files
script/update      # terraform init -upgrade; reports newer cr-terraform-module releases
```

- Conventional commits (cog, commit-msg hook); releases are cut by `.github/workflows/release.yaml` on pushes to `main`.

## Key libraries

- AWS provider (hashicorp/aws >= 5.0) — manages IAM, S3, KMS, Firehose resources
